https://nodejs.org/en/download?utm_source=chatgpt.com


----------------------- 安装运行 前端
1. 安装 Bun
    cd web
    npm install -g bun
    bun --version
2. 安装组件并编译
    bun install --frozen-lockfile
    bun run build
    
3. 如何启动前端
   cd web
   bun run dev -- --port 5173
   
   bun run build
    
----------------------- 安装运行 后端
1. 返回根目录，进行编译
